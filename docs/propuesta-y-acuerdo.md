# Plantilla de propuesta y acuerdo

Plantilla general para documentar un proyecto. No reemplaza revisión profesional sobre la legislación colombiana.

## Propuesta

**Cliente:** [persona o negocio]  
**Proyecto:** [nombre]  
**Fecha:** [fecha]

**Objetivo:** [qué debe lograr el sitio y para quién].

**Entregables:** [número de páginas/secciones], diseño adaptable, interacciones incluidas, archivos fuente, configuración/publicación incluida o excluida.

**Cronograma:** inicio [fecha, sujeto a anticipo y recepción de contenido], primer avance [fecha], entrega prevista [fecha].

**Valor y pagos:** construcción $[COP]; dominio, hosting y terceros [responsable]; anticipo [monto]; saldo [hito]; validez [fecha].

**Revisiones:** Incluye [número] rondas sobre el alcance aprobado. Funciones o páginas adicionales requieren presupuesto y aprobación previa.

## Acuerdo base

1. El desarrollador entrega lo descrito en la propuesta; el cliente suministra textos, fotos, datos de contacto y aprobaciones.
2. El cliente revisa cada avance dentro de [días] hábiles. Retrasos de contenido o respuesta pueden mover la fecha final.
3. El trabajo adicional necesita aprobación escrita y presupuesto aparte.
4. El cliente es titular de sus cuentas de dominio, hosting y servicios conectados y asume renovaciones y cargos de terceros.
5. Fuentes y permisos de uso se entregan según la propuesta después del pago acordado. No se transfieren licencias de terceros que no puedan cederse.
6. El cliente autoriza el uso de marca, textos e imágenes para realizar el proyecto. El desarrollador solo mostrará el resultado en su portafolio si el cliente lo autoriza expresamente.
7. Terminación, devoluciones, soporte y tratamiento de datos se acuerdan por escrito antes de iniciar.
