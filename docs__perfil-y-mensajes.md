## Mensaje inicial

Hola, [nombre]. Vi [detalle real y específico] en [canal público]. Estoy armando sitios web para negocios de [zona] y noté que [oportunidad verificable]. Puedo mostrarte una idea para que tus clientes encuentren [menú/servicios/ubicación/contacto] con más facilidad. ¿Te puedo enviar un ejemplo breve? Soy [tu nombre]; aquí puedes ver mis demos: [enlace].

Personaliza el texto tras revisar la web o red social. Si no responde, espera 5–7 días y envía un único seguimiento respetuoso. Si pide no recibir mensajes, registra “No contactar” y detén el contacto.

## Seguimiento

Hola, [nombre]. Te escribo una vez para dar seguimiento a mi mensaje sobre [idea concreta]. Si ahora no es prioridad, no hay problema. Si te interesa, puedo enviarte alcance y valor después de conocer qué necesitas. Gracias.

## Seguimiento comercial

- Registrar negocio, fuente pública y fecha de revisión.
- Contactar solo por canales comerciales publicados y con mensaje personalizado.
- Hacer máximo un seguimiento sin respuesta; respetar “no contactar”.
- Registrar estado, presupuesto y próximo paso; no almacenar datos innecesarios.
- Revisar semanalmente prospectos, respuestas, reuniones y propuestas.
